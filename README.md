# TeraTerm用マクロ
下記のことが出来ます。

* リストを読み込み、1台・複数選択・リスト内全てのサーバへのログイン
* 踏み台を利用した多段ログイン(2段まで)
* コマンドリストによる、ログイン後処理の自動化(あくまでコマンドを順番に実行するだけです)
* ログの自動取得
  * 年月日、ホストリストの登録名、ダイアログで入力したコメントに応じたファイル名を生成
  * 年月日ごとにディレクトリ自動生成して仕分ける機能

## Version
TeraTerm Macro v 1.0.9

## ログイン方法
マクロ実行時に「個別」「まとめて」「複数選択」から選べます。

|方法|内容|
|--|--|
|個別|リストから1台だけ選んでログインします|
|まとめて|リスト内の全サーバへ順番にログインします|
|複数選択|リストからチェックを付けた分だけ選び、順番にログインします。項目をクリックするたびに `[ ]` ⇔ `[x]` が切り替わり、一番下の「選択完了」を選ぶとログインが始まります|

## 過去の不具合
- TeraTerm 5.0 ~ 5.3でマクロを日本語を含めたパスに配置すると、パスワード設定がうまくいかない(読み込みだけならOK)
  - [こちら](https://github.com/TeraTermProject/teraterm/issues/422)で報告済み 
  - 5.4.0で解消済み

## 動作に必要なもの
### ホストリスト(conf/host.list)
- ログイン情報を記入します
- リストはタブ区切り、文字コードはUTF-8(BOM無し)、改行CR+LFで保存する必要があります
- ファイルが存在しない場合、ダイアログから指定できます
- 行の先頭が#の場合はコメントとして扱います

書式については、 `ホストリスト.xlsm` を参照してください。
なお、TeraTermマクロの仕様上、ホストリストをエディタ等で開いた状態では動作しません。

|表示名|ホスト名|ログインIP①|OS種別①|ログインユーザ①|ログインIP②|OS種別②|ログインユーザ②|
|--|--|--|--|--|--|--|--|
|テストサーバ#1|testsv01|192.168.0.1|Linux|linux||||
|テストサーバ#2|testsv02|192.168.0.2|Linux2|linux|172.16.0.1|Linux|linux|

|項目|用途|
|--|--|
|表示名|リスト選択時に表示される名称|
|ホスト名|hostname -sで表示されるホスト名(ログイン確認に用います)多段ログインの場合は2台目のホスト名|
|ログインIP①|ログイン先のIPアドレス、ホスト名|
|OS種別①|ログイン先のOS種別Linux, ESX|
|ログインユーザ①|ログインユーザ|
|ログインIP②|2台目のログインIPアドレス、ホスト名|
|OS種別②|2台目のOS種別Linux, ESX|
|ログインユーザ②|2台目のログインユーザ|

※OS種別については「Linux」「ESX」を含めば問題ありません。
　ESXはチャレンジレスポンス認証がデフォルトなので認証方式の変更に用いています。 
　また、ログイン時に自動実行されるコマンドやプロンプトの判別が異なります。

#### ホストリスト.xlsm
- host.listシートの内容をもとにホストリストを生成します。
- 記載方法については使い方シートを確認してください。

### パスワードファイル(conf/password.dat) 
- 暗号化されたパスワードが保存されていますが簡単に復元可能です
- ファイルの取り扱いには注意してください
- 将来的にもっと安全な実装がされそうな気配もあるので待ちます
  - [add：ttpmacro setpassword、getpassword暗号化機能追加 #213](https://github.com/TeraTermProject/teraterm/issues/213)
  → 機能は追加されたものの、パスワードファイルのみ盗まれるという状況は考えづらいので保留
- 事前に生成できますが、対象のログイン情報が存在しなければ入力を促されます
- 事前に生成する場合は`パスワードファイル生成.ttl`を実行します
- パスワードログインに失敗してもエントリは更新しません。パスワードファイルを更新し直してください

```
[Password]
[接続先]___[ユーザ名]=[暗号化されたパスワード]
192.168.0.1___root=Slhgq?IC`W-*B:mp3J==gll}
```

### パスワードファイル生成(パスワードファイル生成.ttl)
ログイン先、ユーザ名、パスワードをCSV形式で保存して読み込ませてください。
passwordlist.csvが存在すれば読み込みます。(無ければダイアログから選択)

|ホスト名orIPアドレス|ユーザ名|パスワード|
|--|--|--|
|192.168.0.1|test|test|

### TeraTerm設定ファイル(conf/TERATERM.INI)

TeraTermが起動するときの設定ファイルです。

- 環境による差異をなくすため、マクロと同じディレクトリの設定ファイルを読み込むようにしています
- 好みに応じてカスタマイズしてください
- ただし、ログ取得はマクロで行うので自動取得は入れないようにしてください

### 設定ファイル(sub/設定.ttl)

タイムアウト・認証方法・プロンプト・ウィンドウ整列/ブロードキャストの
メニューIDなど、変更する可能性がある設定を1ファイルにまとめています。
`ログイン用マクロ.ttl`本体を編集しなくても、このファイルを書き換えるだけで
挙動を変更できます。

- `Default_Timeout` : 各種待受のタイムアウト秒数
- `Linux_Authtype` / `ESX_Authtype` : OS種別ごとの認証方法(`password`または`challenge`)
- `Linux_Prompt` / `ESX_Prompt` : OS種別ごとのプロンプトの正規表現
- `Arrange_Menu_ID` / `Broadcast_Menu_ID` : 一括ログイン・複数選択ログインで、
  最後のホストの処理が終わった直後に呼び出すウィンドウ整列・ブロードキャスト
  コマンドのメニューID(既定はそれぞれ「左右に並べて表示」=50815、
  「ブロードキャストコマンド」=50445)。「重ねて表示」にしたい場合は
  `Arrange_Menu_ID`を50813に変更してください。メニューIDの一覧は
  [メニューID表](https://teratermproject.github.io/manual/5/ja/reference/menu_id.html)
  を参照してください。

### ホストリスト管理 & パスワードファイル生成 GUI(HostListGUI.ps1)
`ホストリスト.xlsm` や `passwordlist.csv` を手動編集する代わりに、PowerShellのGUIから
`conf/host.list` の作成・編集と `conf/password.dat` の生成までをまとめて行えるツールです。

- Windows専用(Windows PowerShell / Windows Forms を使用)
- プロジェクトのルートディレクトリ(このREADMEと同じ場所)に配置して実行してください
- 実行例: PowerShellで `powershell -ExecutionPolicy Bypass -File .\HostListGUI.ps1`
  - 既定の実行ポリシーでスクリプトの実行がブロックされる場合は上記のように
    `-ExecutionPolicy Bypass` を付けて実行してください
- **文字コードについて**: このファイルは`Shift-JIS(CP932)`で保存しています。
  Windows PowerShell 5.1(OS付属版)はBOMの無いスクリプトをシステムの
  既定コードページ(日本語Windowsでは Shift-JIS)として読み込むため、他の
  プロジェクトファイル(`host.list`等)と違いUTF-8(BOM無し)のままでは
  日本語部分が正しく読み込まれず動作しません。`host.list`等とは文字コードの
  扱いが異なるので、編集する際は保存時の文字コードに注意してください
  - PowerShell 7系(`pwsh.exe`)で実行する場合はUTF-8(BOM無し)が既定の解釈に
    なるため、pwshで使う場合はUTF-8(BOM無し)への変換が別途必要です

#### できること
画面は「ホストリスト」タブと「パスワード作成」タブに分かれています。

- **ホストリストタブ**
  - ホストリスト(`conf/host.list`)の一覧表示・追加・削除・並べ替え・保存
  - 保存時にタブ区切り/UTF-8(BOM無し)/CRLFで書き出すため、`host.list`の仕様に準拠します
- **パスワード作成タブ**
  - ホストリストのログインIP①/②・ログインユーザ①/②の組み合わせから、重複を排除した
    一覧(IPアドレス・ユーザー名・パスワード)を自動生成します。同じ踏み台等を複数の行から
    参照している場合でも入力は1回で済みます。「ホストリストから一覧を更新」で
    ホストリストタブでの編集内容を反映できます(タブを切り替えた際にも自動更新されます)
  - パスワード欄はグリッド上でマスク表示され、入力もマスク付きで行えます
  - 各行のチェックボックスで生成対象を選びます。**チェックが入っていて、かつユーザー名・
    パスワードの両方が入力されている行だけ**が生成対象になり、どれか1つでも欠けている行は
    何もせず無視されます(エラーにはなりません)
  - パスワードは画面上に一時的に保持するだけで、`host.list`には保存されません。生成に
    成功した行は、画面に平文パスワードが残り続けないよう、チェックとパスワード欄が
    自動でクリアされます
  - 生成時、内部的には既存の`パスワードファイル生成.ttl`(プロジェクトのルート直下に置く必要があります。
    `ttpmacro.exe`はこのファイル自身の場所を基準にconf/password.dat・passwordlist.csvの
    パスを組み立てるため、他の場所へ移動すると生成に失敗します)を`ttpmacro.exe`で実行して
    暗号化しているため、TeraTerm Macro内部の非公開の暗号化仕様を再実装せずに済み、
    生成される`conf/password.dat`は`ログイン用マクロ.ttl`(getpassword)とそのまま互換です
  - 生成に使う平文の`passwordlist.csv`は、`conf/password.dat`の更新を確認できた場合のみ
    自動で削除されます。更新が確認できなかった場合は削除せずに残すので、
    ttpmacroのウィンドウが裏に隠れていないか等を確認してください

#### 初回設定
画面上部で`ttpmacro.exe`のパス(例: `C:\Program Files\teraterm5\ttpmacro.exe`)を
「参照...」から指定してください。パスが未設定・無効なまま生成を実行すると選択ダイアログが
自動で開きます。指定内容は`conf/gui-settings.json`に保存されます
(このファイルは環境固有のパスを含むため`.gitignore`対象です)。

### コマンドリスト(cmdlist/command_[OS種別].list)

- OS種別ごとにコマンドを自動実行させるために利用します
- リストファイルが無ければダイアログから選択するようになっています
- 中身が空で良いので必ず用意してください
- ユーザ入力を促すようなコマンドへの応答は出来ません

たとえば、ホストリストで「Linux_hoge」としている場合は`conf/command_Linux_hoge.list`を準備してください。
